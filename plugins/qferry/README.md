# QFerry Codex Plugin

QFerry is a Codex plugin surface for safe QQ Mail organization workflows.

Current boundary:

- Fixture-first MCP runtime scaffold.
- Read-only QQ Mail posture.
- Preview-only cleanup plans.
- Trace artifacts for e2e runs.

The plugin runtime must be launched from plugin-local `./dist/mcp.js`. Do not point `.mcp.json` at the source checkout.
